ステージングされたgitの変更に機密情報が含まれていないか確認します。

以下のステップを実行してください：

1. `git diff --cached` でステージングされた変更を取得
2. 追加行（`+` で始まる行）を中心に、次のパターンを検索：
   - AWS アクセスキー（`AKIA` で始まる20文字）
   - OpenAI APIキー（`sk-` で始まる）
   - GitHub トークン（`ghp_`, `ghs_`, `github_pat_` で始まる）
   - Slack トークン（`xoxb-`, `xoxp-` で始まる）
   - Google APIキー（`AIza` で始まる）
   - Anthropic APIキー（`sk-ant-` で始まる）
   - プライベートキー（`BEGIN PRIVATE KEY` 等）
   - パスワード・シークレット・トークンのハードコード
   - 認証情報付きデータベース接続文字列
   - `.env` ファイルの機密値

3. 問題が見つかった場合：
   - 検出した機密情報の種類とファイル・行を報告
   - コミットの中止を提案
   - 対処方法（環境変数への移行、`.gitignore` への追加等）を提案

4. 問題がない場合：
   - 「機密情報は検出されませんでした。コミット可能です。」と報告
